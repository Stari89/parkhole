# Library choices for approval

Date: 2026-11-10. Author: `tech-skeptic`. Status: **proposal for Damjan to approve.** Nothing here is decided.

**Already accepted by Damjan:** TypeScript 6.0, the three-part infra split (`infra-ingest`, aggregation job, `municipal-api`), a maintained auth library, MySQL 8, and everything on one Ubuntu host (the NUC).

**How versions were checked:** each version is the current `latest` from `npm view` on 2026-11-10. For Expo apps, the version is the one Expo SDK 58 pins (`bundledNativeModules.json` in `expo@58.0.23`). Install Expo app packages with `npx expo install`, not by hand. Licences come from `npm view`. **(unverified)** marks anything I couldn't check that way, such as Docker images, non-npm tools and runtime behaviour.

## Rules this list respects

- **No AGPL dependencies.** Ultralytics, OpenALPR and MinIO are left out (22a).
- **No public OSM servers.** Basemap, glyphs and sprites are self-hosted (13).
- **No platform reverse geocoding.** Labels come from the tiles. Nothing on the list calls `expo-location` reverse geocoding.

## Points most worth Damjan's attention

1. **MinIO (22a).** It's AGPL, which conflicts with the CLAUDE.md rule, so I pick SeaweedFS instead. Damjan decides whether the rule also covers servers we run unmodified.
2. **Codegen (7).** `openapi-typescript` declares peer `typescript ^5.x`, which conflicts with TS 6, so I pick orval with one generated client per API.
3. **Auth (5a).** Better Auth's Nest adapter is a community package, and I haven't verified that it supports two auth instances in one app. Spike it before building login.
